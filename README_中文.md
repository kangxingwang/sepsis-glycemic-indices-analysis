# 脓毒症血糖研究代码说明

本仓库只整理两部分：`01_cox_rcs` 为两库分别进行的主分析 Cox 与 RCS；`02_machine_learning` 为特征筛选、五算法训练与验证及相关图表。详细方法、输入字段与运行命令见英文 README 和各模块说明。

输入 CSV 必须是已经完成纳入排除、每名患者仅保留一次 ICU 入院的最终队列。仓库中的 CSV 只有表头，没有患者数据。请将真实输入及全部运行结果保存在仓库外的私有目录。

两库原始 28 天结局字段不变；Cox 的 `day28_los` 输入单位为小时，已截断至 28 天，运行时除以 24。Model 3 为年龄、性别、种族、糖尿病、SOFA、Charlson，不含生命体征。NWICU 机器学习使用重新提取四项生命体征的最终数据。

本次已用原私有数据核对 Cox/RCS，比较数值与原结果一致；机器学习完成语法、入口及关键函数一致性检查，没有重新执行耗时的完整训练。

本仓库不包含数据库 SQL、72 小时 landmark、住院/ICU Logistic、Clinical5 增量、纳入排除比较等其余补充分析。因此应在文章代码可用性声明中明确这是核心分析代码，不能表述为全部补充分析均已公开。

GitHub 文件发布与 DOI 存储是两步。此仓库不宣称已经取得 DOI。
